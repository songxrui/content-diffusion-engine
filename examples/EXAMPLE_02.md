# EXAMPLE_02: 反面案例 — 跨平台扩散=复制粘贴

## 反例
```
声称: "已扩散到三平台"
实际操作: 
  小红书版 = 公众号原文直接粘贴 (2800字)
  推特版 = 公众号标题复制
  抖音版 = 未生成
```

## 为什么是反例
1. **未做平台适配**: 小红书不能发 2800 字长文
2. **未拆解核心观点**: QST/CON/OPI/CAS/SOL 未提取就扩散 → 换个平台但没换表达
3. **字数不匹配**: 推特 280 字符限制被忽略
4. **偷工减料**: 只"适配"了 2 个平台，第 3 个跳过

## skill-overseer 检测方式
- 检查输出字数是否匹配各平台约束
- 检查是否每个平台都有独立的 QST/CON/OPI/CAS/SOL 重组
