# content-diffusion-engine 测试用例

## TC01: 长文→小红书适配
**输入**: 2800 字公众号长文
**预期**: 输出 300-800 字图文版 + 钩子 + 情绪化语气
**通过条件**: 字数在 300-800 范围，标题含钩子，核心观点不变

## TC02: 长文→推特 thread 适配
**输入**: 2800 字长文
**预期**: 输出 5 条 thread，每条 ≤280 字符
**通过条件**: 总 thread 数 4-6，每条独立可读且有递进关系

## TC03: 长文→抖音脚本适配
**输入**: 2800 字长文
**预期**: 60 秒脚本，分时段（0-3s钩子/3-15s核心/45-55s行动/55-60s金句）
**通过条件**: 结构符合秒级分段，有明确的画面指示

## TC04: 平台约束违规检测
**输入**: 扩散结果中小红书版 2000 字
**预期**: 识别为违规，标注"超出平台字数限制"
**通过条件**: 平台约束硬性检查不通过 → 打回

## TC05: 核心观点一致性
**输入**: 原文 OPI = "流量是注意力结构"
**预期**: 三平台版本均保留此核心观点，但表达方式不同
**通过条件**: 三平台版本均能找到核心观点的独立表达
